# PaperAssist 0.2.0a2 — Alpha

This alpha improves bibliography extraction, citation counts and reference acquisition.

- **Reconciled citations:** internal PDF links and text detections contribute distinct citation events. Unlinked text mentions remain available, while overlapping text/link detections are counted once.
- **More bibliography links:** additional PDF destination types, hanging indents, repeated-author rows and long lines are supported. Unrecognized or ambiguous destination rows remain unresolved.
- **Cleaner reference lists:** wrapped years and backreference page numbers no longer become fake entries; conference venues stay with numbered references. Lettered appendix headings are recognized without treating known author/title running headers as appendices.
- **Split citations:** recognized citations across adjacent pages count as one event, with page-specific geometry. The count button visits the event once and outlines both parts. Complete citations on consecutive lines or pages remain separate.
- **Broader text recognition:** explicit multi-author lists, known compound surnames, semicolon-separated years, spacing damage and possessive author forms are supported.
- **Readable acquisition lists:** long titles and unbroken identifiers wrap without horizontal scrolling. Checkbox accessibility, keyboard selection and full-title tooltips are preserved.

Earlier reference analyses refresh in the background. Unambiguous existing entry IDs, manual PDF links, retrieval state and acquisition selections are preserved during parser repairs. Original PDFs remain unchanged; saving annotations still requires explicit Save.

Download the Linux x86_64 installer, Windows x86_64 setup EXE or Apple Silicon macOS DMG and verify its matching `.sha256` file. Linux packages require glibc 2.35 or newer. Build provenance, OCR manifests, third-party notices, the GPL license and a combined `SHA256SUMS` file accompany the packages. Close PaperAssist before upgrading. Libraries, saved revisions, notes and preferences remain compatible with `0.2.0a1`.

Citation counts and bibliography coverage remain partial, particularly for damaged OCR, unknown author formats and ambiguous works. Offline OCR recovers metadata and does not add a PDF text layer. Use a test library and keep backups. Windows builds are not Authenticode-signed; macOS builds are ad-hoc signed without Developer ID signing or notarization. Intel macOS and additional architectures are not included.
