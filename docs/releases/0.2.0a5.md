# PaperAssist 0.2.0a5 — Alpha

This maintenance alpha improves reference extraction on manuscript proofs and varied bibliography headings.

- **Automatic margin line-number stripping:** PDF extraction detects outer-margin line numbers (continuous across pages or pagewise, in steps of 1, 5, or 10) by column alignment and top-to-bottom progression, excluding them before bibliography parsing and destination mapping without altering axis ticks or page numbers.
- **Resilient bibliography heading detection:** `References`, `Bibliography`, and `Literature Cited` headings accept optional section numbers and trailing punctuation, with a conservative fallback for trailing margin numbers when bibliography entries immediately follow.
- **Automatic re-analysis:** bumping the extraction version refreshes cached empty or stale reference analyses on next load while preserving manual links and retrieval state.

The update includes all `0.2.0a4` fixes. Libraries, saved revisions, notes and preferences remain compatible; PDFs change only on explicit Save.

Download the Linux x86_64 installer, Windows x86_64 setup EXE or Apple Silicon macOS DMG with its matching checksum. Build provenance, OCR manifests, third-party notices, the GPL license and combined `SHA256SUMS` accompany the packages. Linux requires glibc 2.35 or newer. Close PaperAssist before upgrading.

This remains an alpha. Reference extraction and acquisition remain partial. Windows packages are not Authenticode-signed; macOS packages are ad-hoc signed without Developer ID signing or notarization. Intel macOS and additional architectures are not included.
