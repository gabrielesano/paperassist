# PaperAssist 0.2.0a3 — Alpha

This maintenance alpha fixes the consolidated bug audit and its follow-up PDF edge cases.

- **Safer background work:** job polling and reference updates are synchronized. Reference IDs remain stable through re-analysis, removed IDs are not reused, and a changed reference no longer aborts an acquisition batch. Slow extraction and repair lookups leave reference reads available.
- **Reliable foreign PDF editing:** indirect highlight points and ink strokes, missing or grayscale/CMYK colors, null appearances and reversed annotation rectangles are handled during editing. Existing appearance streams remain preserved where possible; missing appearances are regenerated. Source PDFs change only on explicit Save.
- **Correct citation and note navigation:** author-year links support year suffixes, two-author forms and particle surnames. Destination migration re-extracts PDF links. Rotated text spans merge along the displayed baseline, and narrow punctuation no longer merges separate comment lines into columns.
- **Native window lifecycle fixes:** closing Sources during an access check is safe, repeated close requests share one decision, released views and comment models are freed, queued reading-position restores stop after close, and acquisition offers and citation caches follow the current document.
- **Metadata and retrieval repairs:** local DOI reuse works without Crossref; provider PDF candidates follow the existing HTTPS policy; arXiv fallback, OCR TSV parsing, submission-date handling and refreshed year provenance are corrected. Library reconciliation and preferred-file updates handle the audited edge cases.
- **Linux installer fixes:** empty existing installation directories and trailing slashes work for installation, upgrade and uninstall. Desktop entry and icon cleanup is corrected.

The update also fixes acquisition row refresh and deselection, long citation choices, quick-view promotion, empty PDF page geometry, settings validation, non-ASCII filename fallback, folder inspection errors and library switching while external files are opening.

Download the Linux x86_64 installer, Windows x86_64 setup EXE or Apple Silicon macOS DMG with its matching checksum. Build provenance, OCR manifests, third-party notices, the GPL license and combined `SHA256SUMS` accompany the packages. Linux requires glibc 2.35 or newer. Close PaperAssist before upgrading. Libraries, saved revisions, notes and preferences remain compatible with `0.2.0a2`.

Reference extraction and acquisition remain partial. Offline OCR recovers metadata and does not add a PDF text layer. Windows packages are not Authenticode-signed; macOS packages are ad-hoc signed without Developer ID signing or notarization. Intel macOS and additional architectures are not included.

See the [audit and regression record](https://github.com/gabrielesano/paperassist/blob/main/docs/development/bug-audit-2026-11.md) and [release acceptance](https://github.com/gabrielesano/paperassist/blob/main/docs/development/release-0.2.0a3.md).
