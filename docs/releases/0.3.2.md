# PaperAssist 0.3.2

- **Reader navigation, search, and quoting:** `Ctrl+F` now searches asynchronously in the render worker starting from the current page (`Shift+Enter` searches backwards, `Esc` cancels). Right-click selected text to **Copy with source** (including page range, title, authors, year, and DOI), or set and return to a per-pane reading mark (`Ctrl+Shift+J` / `Ctrl+J`). Pressing `Escape` cancels an in-progress ink or highlight stroke, and modifier keys no longer split strokes.
- **Comments export:** Click **Copy notes** in the **Comments** panel to copy all saved comments on the active paper as Markdown.
- **Library management & work identities:** Remove selected papers from the library with **Remove…** (`Delete`), closing any open tabs or Quick view panes for removed papers. Library lookup and local reuse now support first-class `arXiv` and `bibcode` identifiers alongside DOIs, backed by indexed SQLite manual-link lookup.
- **Batch manual downloads & open-access links:** Use **Open blocked** to open blocked open-access PDF links in your browser, then run **Check folder** in the References toolbar or Acquire dialog to verify and link all matching downloads in one pass. Direct PDF downloads now send `Accept: application/pdf` and optional `mailto:` User-Agent identification.

Download the Linux x86_64 installer, Windows x86_64 setup EXE, or Apple Silicon macOS DMG and its matching SHA-256 checksum. Close PaperAssist before upgrading. The Linux package requires glibc 2.35 or later. The Windows installer is unsigned and the macOS app is ad-hoc signed without notarization.
