# PaperAssist 0.3.1

- Click **Pan** or press `M`, then drag to move the page horizontally or vertically. You can also hold `Space` and drag or drag with the middle mouse button in any reader tool. A tap of `Space` still scrolls down one screen.
- In **Pan** mode, click a PDF link to follow it or drag from the link to move the page. Panning leaves annotations and the current text selection intact.
- Pending reference prompts are canceled when their window is destroyed. The macOS lifecycle tests now keep test arguments out of Cocoa file-open events.

Download the Linux x86_64 installer, Windows x86_64 setup EXE, or Apple Silicon macOS DMG and its matching SHA-256 checksum. Close PaperAssist before upgrading. The Linux package requires glibc 2.35 or later. The Windows installer is unsigned and the macOS app is ad-hoc signed without notarization.
