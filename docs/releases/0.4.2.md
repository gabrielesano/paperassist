# PaperAssist 0.4.2

- Bibliography analysis now checks for stronger reference entries in alternate PDFium reading orders. It handles narrow column gutters, vertical publisher text, false headings in contents pages and tables, and entries joined by the PDF text layer.
- PDFium extraction now places separately drawn accents on their letters. Reference parsing recognizes additional heading and author formats, including reliable numbered lists printed without a heading.
- Reference analysis can use cached local OCR for scans and incomplete text layers. An explicit analysis can recover missing text with bundled OCR. Opening a paper skips that extra processing and uses text already available.
- The library keeps its columns usable in narrower windows and shows per-file details for failed imports and metadata refreshes. Long status messages fit the surrounding controls and remain readable in tooltips or details dialogs.

PaperAssist refreshes cached reference analyses as papers are reopened. Bibliography coverage and citation counts remain partial.

Download the Linux x86_64 installer, Windows x86_64 setup EXE, or Apple Silicon macOS DMG and its matching SHA-256 checksum. Close PaperAssist before upgrading. The Linux package requires glibc 2.35 or later. The Windows installer is unsigned and the macOS app is ad-hoc signed without notarization.
