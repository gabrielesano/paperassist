# PaperAssist 0.2.0a4 — Alpha

This maintenance alpha fixes the toolbar overflow button that could become almost invisible in narrow windows, especially beside the second paper in side-by-side Quick view.

- **Visible overflow menus:** Qt now reserves at least 24 logical pixels for the overflow button on reader and annotation toolbars. A transparent resting border preserves the icon space when the button receives focus.
- **Preserved controls:** existing mouse and keyboard access to hidden actions, page fields, colors and submenus stays available. The controls retain the application theme and work with interface zoom.
- **Safe style cleanup:** the proxy style remains alive while Qt releases toolbar widgets, then is deleted after the toolbar closes. Regression coverage checks geometry, focus stability, menu access and cleanup.

The update includes all `0.2.0a3` bug fixes. Libraries, saved revisions, notes and preferences remain compatible; PDFs change only on explicit Save.

Download the Linux x86_64 installer, Windows x86_64 setup EXE or Apple Silicon macOS DMG with its matching checksum. Build provenance, OCR manifests, third-party notices, the GPL license and combined `SHA256SUMS` accompany the packages. Linux requires glibc 2.35 or newer. Close PaperAssist before upgrading.

This remains an alpha. Reference extraction and acquisition remain partial. Windows packages are not Authenticode-signed; macOS packages are ad-hoc signed without Developer ID signing or notarization. Intel macOS and additional architectures are not included.

See the [release acceptance record](https://github.com/gabrielesano/paperassist/blob/main/docs/development/release-0.2.0a4.md).
