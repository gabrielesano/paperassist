# PaperAssist 0.2.0a6 — Alpha

This maintenance alpha adds a right-click context menu on PDF pages and confines multi-line text selection and highlighting to article prose on line-numbered manuscripts.

- **PDF right-click context menu:** right-clicking in the reader view opens a non-blocking menu with **Copy**, **Highlight**, **Comment**, and **Select all**, plus **Delete comment** or **Delete highlight / ink** when an annotation or comment is selected or clicked directly. Without a text selection, **Comment** opens a page comment on the clicked page; with a selection, it pre-populates the quote anchor. **Highlight** respects read-only quick-view locks and never writes to disk before an explicit Save.
- **Line-number exclusion during selection and highlighting:** multi-line drag selection, copying, highlighting, and comment anchoring detect vertically aligned margin and two-column gutter line numbers (continuous or pagewise, in steps of 1, 5, or 10) and exclude them from selected words while keeping table row numbers and inline digits selectable.
- **Accessibility test stability:** releases non-`QObject` `QAccessibleInterface` wrappers before `WA_DeleteOnClose` dialog teardown, eliminating a Windows Python 3.13 Shiboken pointer-reuse failure.

The update includes all `0.2.0a5` fixes. Libraries, saved revisions, notes and preferences remain compatible; PDFs change only on explicit Save.

Download the Linux x86_64 installer, Windows x86_64 setup EXE or Apple Silicon macOS DMG with its matching checksum. Build provenance, OCR manifests, third-party notices, the GPL license and combined `SHA256SUMS` accompany the packages. Linux requires glibc 2.35 or newer. Close PaperAssist before upgrading.

This remains an alpha. Reference extraction and acquisition remain partial. Windows packages are not Authenticode-signed; macOS packages are ad-hoc signed without Developer ID signing or notarization. Intel macOS and additional architectures are not included.
