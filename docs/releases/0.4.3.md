# PaperAssist 0.4.3

- Numeric citation detection and link cross-checking now expand grouped ranges across prose citations (`papers 10-17`, `Refs. 10–17`, `References 10 to 17`), split brackets and parentheses (`[10]–[17]`, `(10)–(17)`), prefixed or suffixed brackets (`[see 10–17]`, `[e.g., 10–17]`, `[10–17, and references therein]`), additional Unicode dashes and hyphens, body-size dashes inside geometric superscripts, and adjacent hyperlinked endpoints (`EXTRACTION_VERSION = 14`).
- The native PDF reader adds smooth mouse-wheel gliding while preserving touchpad momentum, `Ctrl`+wheel zoom, and `Shift`+wheel horizontal scrolling, cancelling the glide on jumps, key navigation, scrollbar drags, or view hide.
- Main windows and dialogs now display a 1px outline and consistent cross-platform resize grips on the main window status bar and resizable dialogs, while keeping Preferences fixed-size.

PaperAssist refreshes cached reference analyses as papers are reopened. Bibliography coverage and citation counts remain partial.

Download the Linux x86_64 installer, Windows x86_64 setup EXE, or Apple Silicon macOS DMG and its matching SHA-256 checksum. Close PaperAssist before upgrading. The Linux package requires glibc 2.35 or later. The Windows installer is unsigned and the macOS app is ad-hoc signed without notarization.
