# PaperAssist 0.3.0

PaperAssist 0.3.0 lowers multi-paper memory usage, hardens library and annotation integrity, and consolidates the native reader, backend, and packaging architecture.

- **Lower multi-paper memory footprint (-20% to -24% combined RSS):** the render worker shares a single PDFium `Pdf` instance between page rendering and `CitationIndex`, pre-checks destination names and releases transient page word caches during citation lookup, and trims its native heap when tabs close. Hidden reader tabs hibernate inactive `pypdf` reader structures until edited or saved, and the UI process trims its heap after background reference and metadata jobs finish.
- **Library & PDF revision integrity:** `Library` verifies SHA-256 digests for original and saved working PDFs before opening (refusing replaced originals or symlinks while keeping legacy hash-filename compatibility) and passes verified snapshots to the render worker.
- **PDF annotations, rotated pages & outlines:** handles indirect `QuadPoints` and ink stroke arrays, null `/Border` and `/AP` entries, gray/CMYK stroke colors, rotated-page text and note baseline merging, single-step undo for multi-page highlights, and direct PDFium outline extraction (`Pdf.outline()`) without parsing PDFs via `pypdf` on the UI thread.
- **Faster reference resolution & per-host HTTP throttling:** batches publication evidence queries, precomputes document tokens and DOI indexes once per resolution pass, avoids duplicate `extract_text()` passes during reference analysis, reuses thread-local SQLite WAL connections, and throttles external HTTP requests per host (`paperassist.http_client`) so a slow provider never blocks others.
- **Cleaner architecture & packaging:** extracts pure citation matching into `paperassist.citations`, replaces `install(window)` monkey-patching and `WeakSet` pane scanners with explicit composition and `MainWindow.pane_added`, deduplicates Linux installer locking (`lock_common.sh`) and `--uninstall` delegation, moves third-party license texts into `packaging/licenses/` with platform-gated library notices, and routes `packaging/entry.py` through `paperassist.cli:main`.

The update includes all `0.2.0a6` features and fixes. Libraries, saved revisions, notes, and preferences remain compatible; PDFs change only on explicit Save.

Download the Linux x86_64 installer, Windows x86_64 setup EXE, or Apple Silicon macOS DMG with its matching checksum. Build provenance, OCR manifests, third-party notices, the GPL license, and combined `SHA256SUMS` accompany the packages. Linux requires glibc 2.35 or newer. Close PaperAssist before upgrading.

Reference extraction and open-access acquisition remain partial. Windows packages are not Authenticode-signed; macOS packages are ad-hoc signed without Developer ID signing or notarization. Intel macOS and additional architectures are not included.
