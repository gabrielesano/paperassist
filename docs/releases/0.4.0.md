# PaperAssist 0.4.0

- **Zero-copy PDF IPC & worker-side highlight visibility:** Library and edited PDFs now transfer via a parent-owned `SharedMemory` pool (`ctypes.Array` buffer in PDFium) instead of pickling full PDF bytes over pipes, and toggling **Show highlights** filters `/Highlight` and `/InkHighlight` annotations inside the render worker's PDFium pass without rewriting PDFs on the UI thread.
- **PDFium-unified bibliography & expanded citations:** Reference analysis now opens each PDF once via PDFium with position-ordered two-column reading, margin/gutter line-number stripping, PDFium named-destination mapping, superscript and guarded `(n)` numeric citations, and explicit 3+-author inline forms (`Author1, Author2, & Author3 Year`).
- **Searchable sidecar OCR for scanned PDFs:** Right-click a scanned page (**Recognize scanned text (OCR)**) or click **OCR scan** in `Ctrl+F` to cache per-page Tesseract TSV word boxes in `cache/ocr/` (bounded to 256 MiB via LRU eviction), unlocking `Ctrl+F`, text copy, line-aligned highlights, and phrase comments on scanned library PDFs while keeping original files untouched.
- **Catalog scaling, BibTeX, revision compaction, session restore & Windows key protection:** SQLite FTS5 trigram indexing and lightweight projections accelerate large-library filtering, **Copy BibTeX** exports verified papers and references, **Compact revisions…** reclaims space from superseded `working/` snapshots, **Preferences** adds opt-in open-tab/split-view session restoration, and Windows stores `settings.json` API keys with DPAPI encryption under an owner-only protected DACL.

Download the Linux x86_64 installer, Windows x86_64 setup EXE, or Apple Silicon macOS DMG and its matching SHA-256 checksum. Close PaperAssist before upgrading. The Linux package requires glibc 2.35 or later. The Windows installer is unsigned and the macOS app is ad-hoc signed without notarization.
